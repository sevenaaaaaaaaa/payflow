# PayFlow 使用指南

> 核心定位 · Features · 具体用例。写给"产品做好了,就差能收钱"的独立开发者 / 数字创作者,
> 也是官网改版的素材源(与本 README 同源维护)。

---

## 核心定位

**PayFlow 是商业变现引擎:收款 + 订阅 + 推荐裂变 + 佣金结算,一行 `<script>` 嵌进任何页面就是一个能用的收银台。它是进阶层单件——你在用 OpenFlow 后想把变现链路独立复用时装它;只卖几个数字产品的话,装它一个就够。**

装一套电商系统太重;直接对接支付平台原生 API,证书、回调、对账、退款全是坑。PayFlow 给你一行嵌入代码:页面留在原地(任何 CMS / 落地页 / 静态页都行),收款逻辑归它管——一次性与订阅结账、续费失败重试、文件签名下载交付、推荐码归因、佣金冻结解冻提现,每一笔在后台看得清清楚楚。

生产已上线(2026-09-17 起,当前版本 1.0.7),并与 LearnFlow 完成课程售卖联调:购买即入学、退款撤销权益。自检脚本内置 140+ 项检查,发布走自审计门禁。

## Features(按你将真实用到的顺序)

### 1. 三分钟收第一笔
`php payflow/bin/seed.php --dev` 起服务 → 后台建商品 → 把嵌入代码贴进任意 HTML 页 → 点购买走一笔测试订单 → 回后台看订单与看板。

### 2. 多种结账形态
嵌入脚本、托管结账页、弹窗、临时支付链接 `/l/{token}`、兑换券 `/redeem`、发卡库存——按场景挑一种,不用都上。

### 3. 支付通道:适配层即插件
人工确认(默认启用,无需资质)/ 支付宝(RSA2)/ 微信(APIv3)/ 加密货币(静态地址 + 精确金额二维码)。扩展新渠道不改业务代码。

### 4. 数字交付
文件托管 + 签名限时 / 限次下载、License 密钥发放、发票 `/invoice/{token}`——卖虚拟货不需要再拼第三方工具。

### 5. 订阅全闭环
到期自动建续费单 + 邮件支付链接,失败按 1 / 3 / 5 天重试,宽限期降级,订阅健康看板直接看续费率。

### 6. 推荐裂变与佣金结算
推荐码归因、大使层级、佣金冻结 / 解冻 / 冲正、提现审批与打款、`/partner` 大使页、佣金对账单 CSV,每一步可审计。

### 7. 经营看板与治理
GMV、转化、订阅健康、渠道、佣金看板;订单搜索 / 分页 / CSV 导出;API 按 Key 分钟 / 日配额、CSRF、沙箱、操作审计。

### 8. 开放:API + Webhook
`/api/v1/*`(商品 / 订单 / 订阅 / 客户,API Key Bearer / HMAC);出站 Webhook 多目标(HMAC 签名 + 重试),订单事件可喂 UserLoop 或你的任意系统。

## 具体用例(可直接照抄的实战路径)

### 用例 A · 静态页加收款(模板 / 软件授权卖家)
1. 后台「商品」新建商品,拿到 `prod_xxx`;
2. 落地页 `</body>` 前贴 `<script src=".../checkout.js" data-product="prod_xxx">`;
3. 上线人工确认通道,有人下单回后台点「确认到账」;
4. 支付完成自动触发交付:签名下载链接 / License 发到买家邮箱。
**结果**:页面不用搬进任何商店,一个脚本开始收钱。

### 用例 B · 订阅制收费(会员服务 / 持续交付的 SaaS)
1. 商品类型选订阅,设定价与周期;
2. 到期系统自动建续费单,并给用户发支付链接;
3. 未付按 1 / 3 / 5 天重试,宽限期后自动降级;
4. 每周看订阅健康看板的续费率,决定挽留动作。
**结果**:续费不再靠手工记日期,失败有重试、降级有规则、健康度有数。

### 用例 C · 推荐裂变返佣(想老客带新的人)
1. 后台建推荐计划,设佣金比例与大使层级;
2. 老客到 `/partner` 页领推荐码并分享;
3. 订单自动归因,佣金先进冻结期(防退款冲正);
4. 过冻结期解冻,提现走人工审批,对账单 CSV 随时导出。
**结果**:裂变从"口头答应给提成"变成可归因、可审计的流水。

### 用例 D · 临时链接与兑换券(私域成交 / 线下交付)
1. 后台建商品、上传文件库存(发卡形态);
2. 生成临时支付链接 `/l/{token}` 发进私聊 / 社群,或发兑换券 `/redeem`;
3. 买家打开即付,支付完成自动发放签名限时下载;
4. 回后台按 `subject{email, external_id}` 检索这笔订单。
**结果**:私域成交不用再"收款截图 + 手工发货"。

## 常见问题

**Q:支付宝 / 微信现在能直接用吗?**
通道代码就绪(RSA2 / APIv3),但真实商户凭证联调未完成——当前生产以人工确认通道端到端闭环(1.0.7 状态)。接入需在 `data/config.json` 填商户密钥并逐项联调。

**Q:加密货币怎么确认到账?**
生成收款地址 + 精确金额二维码;链上自动监听需外部资质,当前经签名回调或人工确认,退款需人工(链上不可逆)。

**Q:订阅能自动代扣吗?**
免密代扣待商户协议;当前为"到期建单 + 邮件支付链接 + 失败重试"模式。

**Q:佣金会自动打款吗?**
打款走人工审批,不做自动放款;资金域动作(如拼团)不在 PayFlow 单机闭环内。

**Q:支付凭证放哪?**
凭证、商户私钥只写 `data/config.json`(gitignored,服务器为源),永不入库;代码里的 `config/app.php` 只存默认结构。

**Q:改动了怎么验证、怎么发布?**
`php payflow/tests/run.php` 跑 140+ 项自检;发布前 `php payflow/bin/audit.php` 过自审计门禁;部署只同步 `payflow/` 目录(排除 `data/`、`uploads/`)。
